# ERP Web App

## Run locally
1. Open `cmd` in this folder:
   - `cd /d D:\react\ERP Project\web`
2. Install dependencies:
   - `npm install`
3. Start the web app:
   - `npm run web`

## Production web build
- `npm run export`

## Notes
- Update `web\.env` if your backend URL changes.
- The web app uses the same ERP screens and API flow as the mobile app.
